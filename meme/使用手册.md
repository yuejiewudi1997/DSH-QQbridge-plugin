# 梗图合集整理器 · 操作手册

> 适用于 v3.11。程序：`D:\AI\meme-renamer\meme_renamer.py`
> 数据：`<工程目录>\_合集.json`（只有这一个文件会变，改前自动备份）

---

## 一、先认清界面

```
┌─ 左栏（宽 392）──────────────┬─ 中间：图片网格 ─────────────┐
│ ① 合集   双击进入            │  顶部：全选/反选/清空/翻页    │
│   不可以 3    偷窥 2 …       │                              │
│   目标：xxx · N 张           │  每格 = 缩略图 + ✎ + 说明    │
│ ② 标签   合集名 = 标签名      │                              │
│   情绪 / 梗 两栏色块          │                              │
│ ③ QQ 备注                    │                              │
│   同步备注 / 未收藏的也上传   │                              │
│   连接设置 / 同步全部已归类   │                              │
└──────────────────────────────┴──────────────────────────────┘
底栏：撤销加入 | 同步 QQ 备注 | 备注列表 | 移出合集 | 加入合集 →
```

- **目标**：`目标：兴奋 · 2 张` 这一行决定「同步 QQ 备注」把哪一批图发出去。
  进了合集就是合集，没进合集就是侧栏选中的标签。
- **✎**：格子右上角小方框。亮的说明这张有手写备注。

## 二、日常整理（三个最常用的动作）

| 想做的事 | 操作 |
| --- | --- |
| 给图片打标签 | **双击图片** → 直接进当前选中的标签合集 |
| 一次给多张打同一个标签 | 点图选中（可多选）→ 底栏「加入合集 →」→ 点目标标签 |
| 按标签看 | 点 ② 里任意标签色块；再点一次取消 |
| 进某个合集 | ① 里**双击**合集名；出来点左上「← 退出合集」 |
| 改某张的手写备注 | 点格子上的 **✎**，或点图下面那行说明 → 输入 → 回车 |
| 批量改备注 | 底栏「备注列表」→ 点「手写补充」那一格就地改 |

备注规则：**最终备注 = 标签合并 ｜ 手写补充**
例：`兴奋、期待｜元气打招呼开场`；没写手写就只用标签。

## 三、先小批量试跑（以「兴奋」2 张为例）

先确认一次上传效果，再决定要不要全量。

### 第 1 步：进入这个合集

① 合集列表里找到 **兴奋**（显示 `兴奋 2`），**双击**它。

进去后：
- 顶部路径旁边出现 **「← 退出合集」**
- 目标行变成 **`目标：兴奋 · 2 张`**
- 网格只剩 2 张：`979.webp`、`980.webp`

### 第 2 步：勾好两个开关

③ QQ 备注：

- ☑ **同步备注** ← 这是总开关，不勾它就点同步，程序会先问你「现在启用并继续吗」
- ☑ **未收藏的也上传** ← 和「连接设置」里那个勾是同一个开关，勾哪边都算数

勾上「同步备注」后会立刻连一次网关，右边文字变绿：
`已连接 · 收藏 1 张 · 含上传`

### 第 3 步：确认设置（只需做一次）

点 **「连接设置」**：

1. HTTP 地址 `http://127.0.0.1:3000`、accessToken 已填好，不用动
2. **「每批上传上限」改成 300**（默认 100，全量 129 张会被截断）
3. 点 **「测试连接」**，应弹「读到 N 张收藏表情」
4. 点 **「保存」**

### 第 4 步：点「同步 QQ 备注」

底栏那个按钮。弹窗会先把账报给你：

```
合集「兴奋」共 2 张，收藏里有 1 张表情。
其中 0/2 张能对上。
2 张有手写备注，其余用合并后的标签。
对不上的 2 张会上传（上限 300 张）。

继续吗？
```

对得上 0 张是正常的——你 QQ 收藏里现在只有 1 张表情，这两张都还没上传过。
点 **确定**。

### 第 5 步：等进度条走完

2 张 × 1.2 秒 ≈ **3 秒**。完成后弹窗：

```
合集「兴奋」同步完成：

上传 2 张，改了 2 张备注
```

底栏同时显示 `QQ 同步「兴奋」：上传 2 张，改了 2 张备注`。

### 第 6 步：去 QQ 里核对

QQ → 表情 → 我的收藏，找到刚加的两张，看说明是不是：

| 图 | 应显示的备注 |
| --- | --- |
| 979.webp | `兴奋、期待｜元气打招呼开场` |
| 980.webp | `兴奋｜事情成了欢呼庆祝` |

### 第 7 步：不满意怎么改

- **备注写错**：在程序里改（✎ 或备注列表），然后再点一次「同步 QQ 备注」，这次走「改名」，不会重复上传。
- **不想要这两张收藏**：在 QQ 里手动删掉即可，程序不管理删除。
- **想换上限/间隔**：连接设置里改，间隔 1200ms 是防频控的，别调太小。

## 四、全量同步（试跑满意之后）

1. 点左上 **「← 退出合集」**（这一步必须做，否则只会同步「兴奋」那 2 张）
2. 确认 ③ 两个勾还在
3. 点 **「同步全部已归类」**（不是底栏那个）
4. 弹窗会写 `全部已归类（129 张） 共 129 张…`，核对张数 → 确定
5. 129 张 × 1.2 秒 ≈ **2.6 分钟**，期间别关窗口
6. 完成弹窗：`全部已归类（129 张） 同步完成：上传 N 张，改了 M 张备注`

分批也不怕：中断了重跑，已经对上的走「改名」，不会重复上传。

## 五、出问题怎么办

| 现象 | 原因 / 处理 |
| --- | --- |
| 显示「已启用，尚未连上」 | SnowLuma 网关没开，或 bot 掉线。看 `http://127.0.0.1:3000/get_login_info` 能不能返回 |
| 弹「QQ 连不上」 | 同上；本地整理不受影响，可以继续用 |
| 提示「N 张超上限」 | 连接设置里把「每批上传上限」调大，再跑一次 |
| 弹「部分失败」 | 列出前 8 条原因，多半是频控或文件过大，隔几分钟重跑 |
| 弹「同步备注未启用」 | 总开关没勾。点「是」会自动勾上并继续，点「否」什么都不发 |
| 备注被截断 | QQ 描述上限 50 字。当前最长 36 字，正常不会触发 |
| 动图上传失败 | 15 张 GIF 是动图，QQ 收藏对动图支持不稳，失败可忽略 |

## 六、安全性

- 程序**从不修改图片文件**，只改 `_合集.json`。
- 每次改 `_合集.json` 前自动备份为 `_合集.json.bak-<时间戳>`。
- 上传只在勾了「未收藏的也上传」并且你点了确定之后才发生。
- 想完全断开 QQ：取消勾选「同步备注」即可，本地功能照常。
