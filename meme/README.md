# 梗图合集整理器 v3.6

给图片打标签、按标签浏览，并把备注同步进 QQ 收藏表情。

**一句话：合集就是 `_合集.json` 里的一组路径。** 不建文件夹、不复制、不移动、不改名任何图片。
一张图可以同时属于多个合集；合集名 = 标签名，不能自定义。

## 启动

双击 `启动.bat`（无控制台），或 `pythonw.exe meme_renamer.py`。

## 操作

| 操作 | 怎么做 | 结果 |
| --- | --- | --- |
| 选工程目录 | 右上按钮 | 递归扫出所有图片 |
| **双击图片** | 双击缩略图 | **直接加进当前标签**（没合集就自动建） |
| 批量加 | 选图 → 「加入「X」→」 | 一次加多张，跨页选中的一起加 |
| 看某个合集 | 侧栏双击该项 | 网格只显示它；`Esc` 退出 |
| 移出 | 右键图片 → 从「X」移出 | 只删 json 记录 |
| 预览大图 | 右键 → 预览大图 | 双击已经被打标签占用 |
| 新建合集 | 侧栏「新建」 | 用当前标签名建一个空合集，**不能自己取名** |
| 新建标签 | 标签区「新建标签」 | 加到「自定义」组，随时可用 |
| 删除标签 | 标签区「删除标签」 | 只能删自定义的；原始标签拒绝 |
| 备注 | 底栏「备注列表」 | 所有归过类的图，逐张改手写备注 |
| 同步 QQ | 底栏「同步 QQ 备注」 | 写进收藏表情备注 |

## 分页

- 每页固定 **100 张**，顶栏 `◀ [页码] / N 页 ▶`
- **翻页不丢选中**：选中记录的是全集的序号，不是当前页的位置
- 「全选本页 / 反选本页」只作用于当前页，「清空」清全部
- 选集里页码超范围会自动夹到最后一页

## 标签规则

| | 原始标签 | 自定义标签 |
| --- | --- | --- |
| 来源 | 代码里写死的 58 个（26 情绪 + 32 梗） | 自己新建 |
| 能建合集 | ✅ | ✅ |
| 能删除 | ❌ 会弹「原始标签不能删除」 | ✅ 连它的合集一起删 |
| 颜色 | 固定配色 | 按名字哈希取色，稳定 |

- 标签名 = 合集名，**没有单独给合集取名的入口**
- 删除自定义标签只删 json 里的分组，图片文件不动
- json 里手改出现的陌生合集名，会自动归到「自定义」组里显示

## 备注规则

```
最终备注 = 标签合并 ｜ 手写补充
```

手写备注是**补充**，不会盖掉标签：

| 情况 | 结果 |
| --- | --- |
| 有标签、没手写 | `开心、破防` |
| 有标签、有手写 | `开心、破防｜笑死` |
| 没标签、有手写 | `笑死` |
| 都没有 | 空 |

- 标签之间用「、」，手写用「｜」接在后面
- 备注里永远没有 uid、文件名、路径
- 缩略图标题上带 `✎` 表示这张有你写的补充
- 直接点缩略图下面那行说明就能改，输入框里只放手写部分（不含标签），失焦自动保存
- QQ 的 desc 有 50 字上限，标签多 + 补充长时会被截断

## `_合集.json`

```json
{
  "version": 3,
  "collections": {
    "破防": {"images": ["DeepSeek娘/001.webp", "其他图片/782.jpg"]},
    "开心": {"images": ["DeepSeek娘/001.webp"]}
  },
  "notes": {"DeepSeek娘/001.webp": "又开心又破防"},
  "tags": {"custom": ["我的梗"]}
}
```

- 路径是「相对工程目录 + `/`」，整个目录搬走也有效
- 直接改 json 也行（「打开 json」），改完点「刷新」
- 指向不存在图片的记录会自动忽略，`notes` 保留不删

## QQ 备注同步

读 OneBot 的收藏表情，用文件 MD5 跟 `emoji_id` 里的 MD5 对齐：

- 对上的 → `modify_custom_face` 改 `desc`
- 对不上且勾了「未收藏的也上传」→ `add_custom_face` 上传再改备注（受上限约束）
- 已经一致的 → 不发请求（幂等）

QQ 的 desc 上限 50 字符，合并多个标签时可能被截断。

## 注意

- 扫描递归，`_` `.` 开头的目录跳过
- 2291 张图扫描约 0.17 秒
- 网格是「画布图形项 + 只渲染可视行」：一页 100 张但常驻 36~42 格，滚动时增删的是行不是重建整页
- 缩略图只缓存当前页前后各一页（约 120 张），滚回上一页立刻出图不再解码

实测（2000 张图、1800 张的合集）：

| 操作 | 优化前 | 现在 |
| --- | --- | --- |
| 点一个标签 | 重建全部 58 块积木 | **6.5 ms**，只重画新旧两块 |
| 进入 1800 张的合集 | 530 ms | **70 ms** |
| 退出合集 | 200 ms | 瞬时 |
| 翻页 | 前版 77 ms | 46 ms |
| 重扫全库 | 626 ms | 182 ms |
| 100 格渲染 | 252 ms（widget） | 29 ms（画布项） |

几个坑记在这里：
- `pack/pack_forget`、改 Label 文字导致宽度变化，都会触发整窗重排，连带画布 resize 重绘——所以会变的文字控件都固定了宽度
- 合集的「张数」用记录条数，不逐张 stat；进合集时用扫盘缓存的路径集合过滤
- 标签归属查反向索引（rel→合集），不再每次遍历全库
- 删合集/删标签都不可恢复（json 里没有备份），图片永远安全
- 双击 = 加标签，不是预览；预览走右键菜单
